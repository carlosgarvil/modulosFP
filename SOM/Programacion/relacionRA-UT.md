## Detalle por unidad

### UT1. Fundamentos de los sistemas operativos

Esta unidad trabaja los criterios vinculados al reconocimiento de las características de los sistemas operativos, sus elementos funcionales, arquitectura, procesos, sistema de archivos, permisos y licencias.

- 1a. Se identifican y describen los elementos funcionales de un sistema informático.
- 1b. Se codifica y relaciona la información en diferentes sistemas de representación.
- 1c. Se analizan las funciones del sistema operativo.
- 1d. Se describe la arquitectura del sistema operativo.
- 1e. Se identifican los procesos y sus estados.
- 1f. Se describe la estructura y organización del sistema de archivos.
- 1g. Se distinguen los atributos de archivos y directorios.
- 1h. Se reconocen los permisos de archivos y directorios.
- 1i. Se valora la utilidad de los sistemas transaccionales al seleccionar un sistema de archivos.

### UT2. Virtualización y laboratorio

Esta unidad trabaja los criterios relacionados con la creación, configuración y uso de máquinas virtuales como entorno de experimentación y laboratorio.

- 5a. Se diferencia entre máquina real y máquina virtual.
- 5b. Se establecen ventajas e inconvenientes de las máquinas virtuales.
- 5c. Se instala software libre y propietario para crear máquinas virtuales.
- 5d. Se crean máquinas virtuales con sistemas operativos libres y propietarios.
- 5e. Se configuran máquinas virtuales.
- 5f. Se relaciona la máquina virtual con el sistema operativo anfitrión.
- 5g. Se realizan pruebas de rendimiento del sistema.

### UT3. Instalación de sistemas operativos

Esta unidad trabaja el proceso completo de instalación: análisis del hardware, selección del sistema operativo, planificación, configuración inicial, gestor de arranque, incidencias, licencias y actualización.

- 2a. Se verifica la idoneidad del hardware.
- 2b. Se selecciona el sistema operativo.
- 2c. Se elabora un plan de instalación.
- 2d. Se configuran parámetros básicos de la instalación.
- 2e. Se configura un gestor de arranque.
- 2f. Se describen incidencias de la instalación.
- 2g. Se respetan las normas de utilización del software y licencias.
- 2h. Se actualiza el sistema operativo.

### UT4. Windows: administración y configuración

Esta unidad trabaja tareas básicas de configuración y administración en Windows: sesiones, interfaces, entorno personal, sistemas de archivos, instalación de utilidades, asistentes, automatización, usuarios, grupos, procesos, servicios y recursos compartidos.

- 3a. Se realizan operaciones de arranque, parada y uso de sesiones.
- 3b. Se diferencian interfaces de usuario según sus propiedades.
- 3c. Se aplican preferencias en la configuración del entorno personal.
- 3d. Se gestionan sistemas de archivos específicos.
- 3g. Se instalan y desinstalan utilidades.
- 3h. Se utilizan asistentes de configuración del sistema.
- 3i. Se ejecutan operaciones de automatización de tareas.
- 4a. Se configuran perfiles de usuario y grupo.
- 4b. Se utilizan herramientas gráficas para describir la organización de archivos del sistema.
- 4c. Se actúa sobre procesos de usuario según necesidades puntuales.
- 4d. Se actúa sobre servicios del sistema según necesidades puntuales.
- 4h. Se reconocen y configuran recursos compartibles del sistema.
- 4i. Se interpreta la información de configuración del sistema operativo.

### UT5. Windows: mantenimiento, seguridad y recuperación

Esta unidad trabaja recuperación, actualización, optimización, análisis de actividad, rendimiento y mantenimiento de almacenamiento en Windows.

- 3e. Se aplican métodos para la recuperación del sistema operativo.
- 3f. Se configura la actualización del sistema operativo.
- 4e. Se aplican criterios para optimizar la memoria disponible.
- 4f. Se analiza la actividad del sistema a partir de las trazas generadas.
- 4g. Se optimiza el funcionamiento de los dispositivos de almacenamiento.
