# A02. Observacion de procesos reales

## Descripcion

Actividad practica para identificar procesos reales en un sistema operativo mediante herramientas graficas o de terminal. El alumnado revisara informacion basica como nombre del proceso, consumo de CPU, consumo de memoria, usuario asociado y estado.

## Criterios relacionados

- 1c. Se han analizado las funciones del sistema operativo.
- 1e. Se han identificado los procesos y sus estados.

## Producto esperado

Tabla breve con varios procesos observados y una explicacion sencilla de que aplicacion o servicio puede estar asociado a cada uno.
