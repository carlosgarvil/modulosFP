# A04. Comparativa Windows/Linux

## Descripcion

Actividad de comparacion guiada entre Windows y Linux centrada en funciones del sistema operativo, interfaz, organizacion de archivos, gestion de procesos, permisos y modelo de licencias. El objetivo es reconocer similitudes y diferencias sin entrar aun en administracion avanzada.

## Criterios relacionados

- 1a. Se han identificado y descrito los elementos funcionales de un sistema informatico.
- 1c. Se han analizado las funciones del sistema operativo.
- 1f. Se ha descrito la estructura y organizacion del sistema de archivos.
- 1h. Se han reconocido los permisos de archivos y directorios.

## Producto esperado

Tabla comparativa breve con los aspectos principales de ambos sistemas y una conclusion razonada sobre escenarios de uso adecuados para cada uno.
