# Introducción a la unidad

## Objetivo de la unidad

En esta unidad se estudia qué es un sistema operativo, qué funciones cumple y por qué es una pieza central en cualquier sistema informático.

El objetivo no es memorizar nombres de sistemas, sino comprender qué problemas resuelve un sistema operativo:

- Permite usar el hardware sin tratar directamente con sus detalles internos.
- Organiza la ejecución de programas.
- Gestiona memoria, archivos, dispositivos y permisos.
- Proporciona una interfaz para que las personas usuarias y las aplicaciones interactúen con el equipo.

## Punto de partida

Un ordenador no es solo una máquina física. Para que pueda utilizarse hacen falta varias capas:

1. Hardware.
2. Firmware.
3. Sistema operativo.
4. Aplicaciones.
5. Usuarios.

El sistema operativo actúa como intermediario entre las aplicaciones, el hardware y las personas.
