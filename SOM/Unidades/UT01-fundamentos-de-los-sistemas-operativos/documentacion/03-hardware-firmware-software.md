# Hardware, firmware y software

## Hardware

El hardware es la parte física del sistema informático.

Incluye componentes como:

- Procesador.
- Memoria RAM.
- Placa base.
- Disco o unidad SSD.
- Tarjeta gráfica.
- Tarjeta de red.
- Periféricos de entrada y salida.

## Firmware

El firmware es software de bajo nivel grabado en un dispositivo. Permite inicializar y controlar el hardware antes de que el sistema operativo tome el control.

Ejemplos:

- BIOS.
- UEFI.
- Firmware de una impresora.
- Firmware de un router.

## Software

El software es el conjunto de programas, datos e instrucciones que hacen funcionar el sistema.

Puede dividirse en:

- Software de sistema.
- Software de aplicación.
- Herramientas de desarrollo.

## Papel del sistema operativo

El sistema operativo pertenece al software de sistema y se encarga de coordinar los recursos del equipo.

Sus funciones principales son:

- Gestionar procesos.
- Gestionar memoria.
- Gestionar archivos.
- Gestionar dispositivos.
- Controlar usuarios y permisos.
- Ofrecer una interfaz de uso.
