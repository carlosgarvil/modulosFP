# Sistemas de archivos, directorios y permisos

## Sistemas de archivos

Un sistema de archivos define cómo se organizan, almacenan y recuperan los datos en una unidad de almacenamiento.

Ejemplos habituales:

- NTFS.
- FAT32.
- exFAT.
- ext4.
- APFS.

## Archivos

Un archivo es una unidad de información almacenada con un nombre y una ubicación.

Puede contener:

- Texto.
- Imágenes.
- Programas.
- Configuraciones.
- Datos de usuario.

## Directorios

Un directorio o carpeta permite organizar archivos y otros directorios.

Los sistemas operativos utilizan estructuras jerárquicas para organizar la información.

Ejemplo:

```text
/
├── home/
│   └── usuario/
└── etc/
```

## Atributos

Los archivos y directorios pueden tener atributos como:

- Nombre.
- Tamaño.
- Fecha de creación.
- Fecha de modificación.
- Propietario.
- Permisos.
- Estado oculto o solo lectura.

## Permisos

Los permisos controlan quién puede acceder a un archivo o directorio y qué puede hacer.

Operaciones habituales:

- Leer.
- Escribir.
- Ejecutar.

## Sistemas transaccionales

Algunos sistemas de archivos incorporan mecanismos para reducir errores ante apagados inesperados o fallos durante operaciones de escritura.

Estos mecanismos ayudan a mantener la coherencia de los datos.
