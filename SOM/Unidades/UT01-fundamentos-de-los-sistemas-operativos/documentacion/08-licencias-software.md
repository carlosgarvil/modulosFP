# Licencias de software

## Qué es una licencia

Una licencia de software define las condiciones legales de uso de un programa.

No todo el software puede copiarse, modificarse o distribuirse libremente.

## Software propietario

El software propietario limita el acceso al código fuente y establece condiciones concretas de uso.

Ejemplos habituales:

- Windows.
- Microsoft Office.
- Aplicaciones comerciales de pago.

## Software libre

El software libre garantiza libertades para:

- Usar el programa.
- Estudiar cómo funciona.
- Modificarlo.
- Distribuir copias.
- Distribuir versiones modificadas.

## Código abierto

El código abierto permite acceder al código fuente. En muchos casos coincide con el software libre, aunque el enfoque y las condiciones concretas pueden variar según la licencia.

## Ejemplos de licencias

- GPL.
- MIT.
- Apache.
- BSD.
- Licencias propietarias.
- Licencias OEM.

## Importancia en sistemas operativos

La licencia influye en:

- Coste.
- Posibilidad de modificación.
- Distribución.
- Soporte.
- Uso legal en una empresa o centro educativo.

## Idea clave

Instalar y usar software también implica cumplir condiciones legales. Un técnico debe conocerlas para tomar decisiones correctas.
