# Resumen y repaso

## Ideas principales

- El sistema operativo actúa como intermediario entre hardware, aplicaciones y usuarios.
- Hardware, firmware y software son capas distintas del sistema informático.
- El kernel es la parte central del sistema operativo.
- Los procesos son programas en ejecución.
- Los hilos permiten dividir la ejecución dentro de un proceso.
- La planificación de CPU reparte el uso del procesador.
- La gestión de memoria permite aislar procesos y aprovechar la RAM.
- Los sistemas de archivos organizan la información en archivos y directorios.
- Los permisos controlan el acceso a la información.
- Las licencias definen las condiciones legales de uso del software.

## Conexión con las prácticas

Durante la unidad se recomienda realizar estas prácticas:

- Usar un simulador de procesos para visualizar estados y cambios.
- Observar procesos reales con herramientas del sistema operativo.
- Explorar la estructura de archivos y directorios.
- Comparar cómo Windows y Linux representan procesos, archivos y permisos.
