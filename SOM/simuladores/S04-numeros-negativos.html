Ideas clave

  • El mismo patrón de bits puede tener distintos significados.
  • El número de bits determina el rango.
  • Signo y magnitud tiene dos ceros: +0 y −0.
  • Complemento a 2 tiene un único cero y se usa habitualmente para enteros con signo.
  • Para interpretar bits necesitamos conocer el tipo de dato.
