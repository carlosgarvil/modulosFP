Una equivalencia histórica

Cuando el programa era una baraja de tarjetas

Antes de escribir programas en una pantalla, era habitual perforarlos en tarjetas. Una tarjeta representaba normalmente una línea y sus 80 columnas guardaban caracteres: letras, números, espacios y símbolos.

Tarjeta de programa · ejemplo8 de 80 columnas
12345678
SUMA␠4␠3 — cada columna vertical codifica un carácter

¿Cómo se lee esta tarjeta?

Las filas se llaman 12, 11, 0, 1…9. La posición o combinación de agujeros de una columna identifica un carácter.

  • 4Los números usan una perforación: el 4 perfora la fila 4.
  • AMuchas letras combinan una zona y un número: A = filas 12 + 1.
  • SOtra zona produce otras letras: S = filas 0 + 2.
  • ␠Un espacio se representa dejando la columna sin perforar.

Por eso SUMA 4 3 ocupa ocho columnas, aunque algunas tengan uno, dos o ningún agujero.

Actividad: construye una pequeña baraja de programa

En los sistemas con tarjetas, un programa podía ocupar muchas tarjetas: normalmente una línea de código por tarjeta. Crea esta versión didáctica, inspirada en el FORTRAN de formato fijo:

Programa · 6 tarjetas
READ *, A
READ *, B
SUM = A + B
PRINT *, SUM
STOP
END
Datos · 2 tarjetas
4
3

Estas tarjetas proporcionan, por separado, los valores de A y B; no son instrucciones del programa.

  1. Selecciona FORTRAN Statement para las seis tarjetas del programa.
  2. En cada tarjeta nueva, pulsa dos veces Tab para llegar al campo de instrucciones, escribe una línea y pulsa Enter.
  3. Crea después dos tarjetas de tipo DATA: una con 4 y otra con 3.
  4. Compara las apariciones de A, B y SUM: el mismo carácter debe producir siempre el mismo patrón de agujeros.
  5. Coloca las tarjetas de programa en orden y mantén las tarjetas de datos separadas. Haz una captura de las ocho.
Abrir perforadora ↗
