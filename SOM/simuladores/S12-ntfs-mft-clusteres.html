La idea clave

En NTFS, el directorio permite encontrar un registro de la MFT. Ese registro contiene atributos como $FILE_NAME y $DATA. Los datos pueden estar dentro del registro (residentes) o en clústeres señalados por él. Este disco pequeño es un modelo para aprender el recorrido.

Volumen / partición NTFS

MFT · Tabla maestra de archivos

Es el índice central de NTFS. Sus registros describen archivos y directorios mediante atributos como $FILE_NAME y $DATA.

Pulsa una caja o pasa el ratón para obtener ayuda. Las cajas representan funciones: no indican tamaños ni posiciones físicas fijas y algunas categorías se solapan.

4. Clústeres de datos y $Bitmap
Un 1 significa ocupado; un 0, disponible. Los archivos residentes no necesitan clústeres de datos externos en este modelo. Cada clúster representa 4 KiB.
El borde discontinuo indica datos que el simulador conserva tras borrar. En un equipo real su recuperación no está garantizada.
