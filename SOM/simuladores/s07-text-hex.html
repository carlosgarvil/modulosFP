Del texto al hexadecimal

Descubre cómo se representa un texto byte a byte mediante UTF-8.

Texto

Pasa el ratón por un carácter o haz clic para fijarlo. También puedes usar el cursor del campo de texto.

Contenido HEX (UTF-8)

Cada casilla es un byte. Escribe dos dígitos hexadecimales (00–FF) para modificar el texto.

Qué estás viendo

UTF-8 usa un byte para los caracteres ASCII y varios para muchos otros símbolos. Por ejemplo, una letra común suele ocupar 1 byte, ñ ocupa 2 bytes, € ocupa 3 y muchos emoji ocupan 4.

Si introduces una secuencia que no es UTF-8 válida, el navegador muestra el carácter de sustitución �. Los bytes incorrectos se conservan para que puedas corregirlos y aparecen marcados en rojo.

Tabla ASCII

ASCII contiene 128 códigos, del 0 al 127. Los códigos del 0 al 31 y el 127 son caracteres de control; los demás son imprimibles. En UTF-8, todos ellos conservan exactamente el mismo valor y ocupan un byte.
